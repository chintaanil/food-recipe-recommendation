# Food Recipe Recommendation System

A full-stack web application that helps users discover and explore food recipes based on their interests and preferences.

## Features

- User Registration and Login
- Secure Authentication
- Veg Recipe Recommendations
- Non-Veg Recipe Recommendations
- Recipe Categories
- User Profile Management
- Responsive User Interface
- MongoDB Database Integration

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Authentication
- JWT (JSON Web Token)
- bcryptjs

backend/

## Installation

1. Clone the repository

```bash
git clone https://github.com/chintaanil/food-recipe-recommendation.git
```

2. Navigate to the project folder

```bash
cd food-recipe-recommendation
```

3. Install dependencies

```bash
npm install
```

4. Create a .env file and configure the required environment variables.

5. Start the application

```bash
npm run dev
```
